# Google Colab CLIP Inference Instructions

These are instructions for how to run the CLIP model on the UCF101 dataset for this project.

The notebook (or .py file) in this folder can be used in Google Colab to run the CLIP on the UCF101 dataset and produce a new dataset that has replaced all the video files with .pt files. These files store the embeddings generated by the CLIP model for each frame.

To run the inference follow these steps:
1. Compile the ucf101_subset into a .zip
2. Upload the .zip to a location on your Google Drive
    - The default location in the notebook is `My Drive/Dissertation/data/ucf101_subset.zip`
3. Start a new Colab Notebook and upload the `CLIP_UCF101_runner.ipynb`
4. Make sure the runtime is using a GPU (e.g. T1)
5. Near the top of the notebook there are many constants for defining the location of files. You can set `DRIVE_ZIP_PATH` to where you uploaded the .zip file. You can also set `GDRIVE_OUTPUT_DIR` to determined where the output will be saved. By default both of these use your Google Drive.
6. Run each of the cells
    - you will have to allow access to your Google Drive so that this notebook can read the dataset from the .zip and write the embeddings back to your Google Drive.
    - The code will download the CLIP model and use it to run inference on the Videos in the dataset (This may take a long time, ~1 hour)
7. Once the final cell has finished running, you will find the new dataset of embeddings at the location `GDRIVE_OUTPUT_DIR`.
8. You should download the generated embeddings dataset and add the folder into the `data` directory in this project
